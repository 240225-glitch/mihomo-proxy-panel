# 本机代理（mihomo + 免费节点）

mihomo 内核 + 网页控制台：网页开关代理、切节点、看流量，主机统一签发子账号，
子账号只能用代理，绕不过 7891 的鉴权。

## 从零部署

1. 装 Node.js 18+
2. 下载 mihomo 内核，放到 `mihomo\mihomo-windows-amd64.exe`
   （<https://github.com/MetaCubeX/mihomo/releases>）
3. 复制配置：`copy mihomo\config.example.yaml mihomo\config.yaml`
4. 启动：双击 `panel\start-panel.bat`，或桌面快捷方式 **代理控制台**
5. 首次启动会在控制台打印管理员账号密码，登录后到「账号」页改密码、发子账号

> `panel\users.json`、`mihomo\config.yaml`、内核 exe、订阅缓存都不进仓库，
> 避免密码和二进制文件提交到 git。

## 日常使用

| 操作 | 说明 |
|---|---|
| 双击桌面 **启动代理** | 弹出登录框，输入账号密码后启动 |
| 双击桌面 **停止代理** | 关闭内核并恢复直连 |
| 双击桌面 **代理控制台** | 打开网页控制台（127.0.0.1:8080） |

- 账号 / 密码：见 `panel\users.json`（首次启动控制台会自动生成管理员）

启动后会打开系统代理（浏览器、大部分软件立即生效）。
启动时脚本会自动等节点就绪，一般 5~30 秒。

## 端口

| 端口 | 用途 | 是否要密码 |
|---|---|---|
| `127.0.0.1:7890` | 本机 HTTP/SOCKS5 | 否 |
| `0.0.0.0:7891` | 局域网其他电脑 | 是（子账号） |
| `0.0.0.0:8080` | 网页控制台 | 是（管理员 / 子账号） |

控制台 API：`127.0.0.1:9090`（仅本机）

## 网页控制台

双击桌面 **代理控制台**，或运行 `panel\start-panel.bat`，然后打开
`http://127.0.0.1:8080`，用管理员账号登录。

- 概览页顶部可以**开关代理**（启动/停止内核 + 系统代理），不用再点桌面快捷方式
- 看实时流量、切节点、断连接、看日志
- **账号** 页可以给同网络的设备发子账号：子账号只能用代理和改自己的密码，
  没有管理员权限，也绕不过 7891 的鉴权

细节见 `panel\README.md`。

## 局域网共享

隔壁电脑把代理指向 `本机IP:7891`，弹窗时填控制台里创建的子账号。
本机 IP 用 `ipconfig` 查看，当前是 `10.20.20.114`。

前提：
1. 本机防火墙放行 TCP 7891 —— 需要管理员运行 `allow-lan-firewall.bat`
2. 路由器没有开 AP / 客户端隔离
3. 本机一直开着，代理在运行

## 文件说明

```
proxy/
├── start-auth.ps1        启动（登录框 + 启动内核 + 设置系统代理）
├── stop-auth.ps1         停止（关代理 + 杀进程）
├── make-shortcuts.ps1    重建桌面快捷方式
├── allow-lan-firewall.bat 放行局域网端口（需管理员）
├── start.bat / stop.bat  无登录的旧版脚本，保留备用
├── panel/                网页控制台（见 panel/README.md）
└── mihomo/
    ├── mihomo-windows-amd64.exe   内核（开源 mihomo v1.19.33）
    ├── config.yaml                配置：订阅源、分组、端口、认证
    └── free.yaml                  自动下载的节点列表（每小时刷新）
```

## 配置要点（config.yaml）

- 节点源：`raw.githubusercontent.com/ermaozi/get_subscribe/.../v2ray.txt`
- `AUTO` 分组自动选最快，`TH` 分组只选泰国节点
- 健康检查 180 秒一轮，挂了自动切
- 节点存活率约 60%，掉光就重新双击启动

## 已知限制

- 只对走系统代理的程序生效；游戏客户端需要 TUN 模式（未启用）
- 免费节点带宽有限，不适合大流量
- 密码明文写在 `start-auth.ps1` 里，介意可以改成读环境变量

## 排错

1. 网页全打不开 → 双击 **停止代理**
2. 想换节点 → 重新双击 **启动代理**
3. 想恢复出厂 → 停止后删掉整个 `proxy` 目录，并确认系统代理已关闭
