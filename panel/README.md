# 代理控制台（Web 面板）

给 mihomo 套一个网页控制台：开关代理、看节点、切节点、看流量、看连接、看日志，
并且由主机统一签发子账号，子账号只能用代理，绕不过鉴权。

```
浏览器 ──HTTP──> panel(8080) ──HTTP──> mihomo API(127.0.0.1:9090)
                      │
                      ├── 静态页面 / 登录会话 / 角色权限
                      └── 改写 mihomo 的 listeners.users（子账号）
```

内核的 9090 只监听本机，外部设备只能走 8080（面板）和 7891（代理），两边都要账号。

---

## 启动

| 方式 | 操作 |
|---|---|
| 桌面快捷方式 | 双击 **代理控制台** |
| 命令行 | `panel\start-panel.bat` |
| 只起面板 | `cd panel && node server.js` |

启动脚本会检查内核，没跑就拉起来，然后打开 `http://127.0.0.1:8080`。

### 角色

| 角色 | 能做什么 |
|---|---|
| 管理员（主机） | 开关代理、切节点、看连接/日志、创建/删除/重置子账号、改自己的密码 |
| 子账号 | 用代理、看自己的连接信息、改自己的密码 |

管理员账号在 `panel\users.json`（首次启动自动生成，也可手动修改）。

---

## 网页开关代理

概览页顶部有一个开关，等同于以前的「启动代理 / 停止代理」：

- 开：启动 mihomo 内核 + 打开 Windows 系统代理（`127.0.0.1:7890`）
- 关：关闭系统代理 + 结束内核进程

只有管理员能操作。子账号看不到这个开关。

---

## 子账号与「绕不过鉴权」

管理员在 **账号** 页新建子账号，填用户名、密码（留空自动生成），创建后：

1. 账号写入 `panel\users.json`
2. 面板自动改写 `mihomo\config.yaml` 的 `listeners.users`
3. 调用 `PUT /configs?force=true` 热重载内核，立刻生效
4. 子账号拿到的地址是 `主机IP:7891`

代理侧的鉴权是 mihomo 原生做的，不是前端做的：

| 请求 | 结果 |
|---|---|
| 不填账号密码 | `407 Proxy Authentication Required` |
| 密码错误 | `403` |
| 正确 | 正常转发 |

也就是说，知道地址也进不来，必须拿到管理员下发的账号。`7890` 只绑 `127.0.0.1`，
只有主机自己能免密用；局域网设备只能走 `7891`。

子账号在面板里也受限：

- `/api/core/*`（内核 API）→ 403
- `/api/users`（账号管理）→ 403
- `/api/proxy/*`（开关代理）→ 403
- 只能访问 `/api/me`、`/api/me/password`

删除子账号会立刻重写配置并热重载，对方当场断开，不需要重启。

## 局域网

面板监听 `0.0.0.0:8080`，代理监听 `0.0.0.0:7891`。别人打不开通常是防火墙或网络隔离：

1. **防火墙**：管理员运行 `panel\allow-panel-firewall.bat`（放行 8080 / 7891）
2. **AP 隔离**：公司/公共 WiFi 常开客户端隔离，`ping 主机IP` 不通就是它
3. **地址**：Windows 用 `http://主机名:8080`，手机用 `http://IP:8080`

### 别人怎么用代理

在对方设备上：

| 系统 | 设置 |
|---|---|
| Windows | 设置 → 网络 → 代理 → 手动 → 地址 `主机IP`，端口 `7891` |
| macOS | 系统设置 → 网络 → 代理 → 网页代理(HTTP) + 安全网页代理(HTTPS) |
| iOS | Wi-Fi → 配置代理 → 手动 |
| Android | Wi-Fi → 修改网络 → 高级 → 代理 → 手动 |

然后浏览器弹窗输入子账号的用户名和密码。

> 网页改不了对方系统的代理设置，那需要对方机器上的权限。面板负责的是「发账号」和「管代理」。

---

## 安全说明

- 面板和代理都是 **HTTP 明文**，局域网内抓包能看到密码。只在内网用，别映射到公网。
- `users.json` 和 `mihomo\config.yaml` 里是明文密码（mihomo 鉴权要求明文）。目录别同步到网盘/Git。
- 会话是 HMAC 签名 Cookie，12 小时有效；连续输错 8 次锁定 10 分钟。
- 9090 只监听 127.0.0.1，外部设备无法直接调内核 API。
- 子账号看不到别人、看不到连接列表、看不到节点管理。
- 想彻底停掉对外服务：关掉网页开关，或直接结束 `node` 进程。

## 文件

```
panel/
├── server.js                  服务端（登录、角色、账号同步、内核反代、开关代理）
├── config.json                端口、内核地址、代理地址
├── users.json                 账号（明文密码，权限 600）
├── start-panel.bat / .ps1     启动
├── allow-panel-firewall.bat   管理员放行 8080 / 7891
├── lib/set-proxy.ps1          改 Windows 系统代理 + 刷新 WinINET
├── .session-secret            自动生成的会话签名密钥

    ├── index.html
    ├── style.css              暖纸 + 陶土配色，圆角气泡
    ├── app.js
    └── favicon.svg
```

## 排错

| 现象 | 处理 |
|---|---|
| 页面打不开 | `netstat -ano \| findstr :8080` 看服务是否在跑 |
| 开关点了没反应 | 看 `start-panel.bat` 窗口有没有报错；内核路径是否对 |
| 子账号连不上 | 确认 `config.yaml` 的 `listeners.users` 里有它，且 7891 在监听 |
| 子账号改完密码立刻生效吗 | 是，保存即热重载 |
| 节点延迟全是「—」 | 点「测试延迟」触发一次健康检查，约 1 分钟 |
| 其他设备打不开 | 先 `ping`，再查防火墙，最后怀疑 AP 隔离 |
| 忘记管理员密码 | 停掉面板，编辑 `users.json` 改 `pass`，再启动 |
